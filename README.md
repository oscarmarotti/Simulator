# أكاديمية الكهرباء

تطبيق ويب تعليمي تفاعلي للكهرباء (React + TypeScript + Vite)، مُجهز كـ PWA قابل للتثبيت على الموبايل. الواجهة بالكامل بالعربية (RTL).

## الأدوات

- **حاسبة الأحمال** (`src/features/loadCalculator`): تحسب القاطع المناسب، مقطع الكابل، ونسبة هبوط الجهد بناءً على نوع الحمل، القدرة، الجهد، والمسافة، باستخدام جداول IEC قياسية.
- **سيموليتور الدوائر الكهربائية** (`src/features/circuitSimulator`): لوحة رسم بالسحب والإفلات لبناء دوائر كهربائية من مصدر AC، قواطع، مفاتيح، فيوزات، ريلي، لمبات، وموتورات، مع محاكاة فيزيائية حقيقية للتيار والجهد والأعطال.

## محرك الحساب

`src/engine/circuitEngine.ts` يحل الدائرة كل مرة عبر:

1. **Union-Find بمسارين** (`src/engine/graph.ts`): مسار صارم (Strict) للأسلاك والقواطع/المفاتيح المقفولة فقط، لاكتشاف القصر المباشر وتحديد هل الموتور متصل مباشرة بالمصدر؛ ومسار التدفق (Flow) الذي يضيف الأحمال كموصلات لتتبع أي دائرة حية.
2. **حل شبكة مقاومات (Nodal Analysis)** (`src/engine/solveOnce.ts`): كل قاطع/مفتاح/فيوز مغلق له مقاومة صغيرة جدًا، وكل حمل له مقاومة مشتقة من القدرة والجهد الاسمي، فيُحسب التيار والجهد الفعليين عبر كل عنصر بدقة (بما في ذلك توزيع الجهد بين الأحمال المتسلسلة).
3. **حل الريلي على مرحلتين**: مرحلة أولى بافتراض كل الكونتاكتات مفتوحة لتحديد حالة الملف، ثم إعادة الحل بالكونتاكتات النهائية.
4. **حلقة تقارب** لفصل القواطع، حرق الفيوزات، تعطل الموتور (Stall)، وحرق الأحمال غير المحمية، حتى تستقر الدائرة.

## التطوير

```bash
npm install
npm run dev       # تشغيل بيئة التطوير
npm run test      # تشغيل اختبارات محرك الدائرة (Vitest)
npm run build     # بناء نسخة الإنتاج
```
